# Hamburgueria Artesanal

Projeto A2 da disciplina de Front-End da Universidade Cruzeiro do Sul (UNICSUL). A proposta é aplicar os conteúdos estudados ao longo do semestre — HTML, CSS e JavaScript — no desenvolvimento de uma loja virtual de hambúrgueres artesanais.

## Sobre o projeto

Na loja, o cliente pode escolher o lanche de sua preferência e personalizar o pedido com adicionais. Entre as opções estão bacon, cheddar e o dobro de proteína. Também é possível incluir batata frita e refrigerante para completar a refeição.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivo acadêmico

Este trabalho reúne os conhecimentos desenvolvidos durante a disciplina em uma aplicação prática, com foco na apresentação de produtos e na personalização de pedidos.
